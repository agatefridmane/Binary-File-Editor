I built a Java command-line program that stores integers in a binary file, displays them, and removes a selected number.
- Create asks how many integers to store, then writes the numbers I enter to a binary file.
- Calculate removes every occurrence of a chosen number. It copies the remaining integers to a temporary file in their original order, then replaces the original file.
- View reads the integers from the file and displays them in the terminal.
This project gave me practice reading and writing binary data, handling the end of a file, and using a temporary file to update stored data.
